# Algorithm Validation

Detail: `.claude/docs/skill-references/extended/algorithm-validation.md`.

- Define inputs, outputs, invariants, and edge cases before implementing.
- Property-based tests for non-trivial algorithms (fuzz inputs, assert invariants).
- Benchmark before claiming "optimized". Provide before/after numbers.
- Document complexity (time + space) in a comment when non-obvious.
